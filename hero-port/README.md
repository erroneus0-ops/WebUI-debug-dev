# HERO BASIC port — work in progress

This subdirectory is a separate side-project from the XRoar WebUI debugger
work happening elsewhere in this repo. It contains an in-progress port of
Nick Marentes' "H.E.R.O." (Extended Color BASIC, CoCo 1/2/3, v1.1) from
interpreted BASIC to a compiled toolchain (ugBASIC), preserving the
undocumented SG12 semigraphics trick the original relies on.

Source game: https://nickmarentes.com/ProjectArchive/hero.html
Free to download, and the author explicitly invites optimization/porting.

Status: repo access + CI scaffolding being set up. Port itself in progress.
